# MaiBot AI 唱歌插件与推理服务

本项目由仓库根目录的 MaiBot 插件和独立的 GPU 推理服务 `server/` 组成。插件接收点歌命令和模型工具调用，通过 HTTP 请求服务端生成歌曲片段，再交给支持 `voiceurl` 自定义消息的适配器发送。

支持 `/唱 歌名`、`/重唱`、`/清空唱段` 和自然对话点歌；可在命令中指定变调、时长等参数。默认男声变调基准为 +8 半音，实际自动变调还会根据检测结果调整。

## 环境与模型

- 插件端：MaiBot、兼容的 `maibot-plugin-sdk` 和 `aiohttp`。语音发送目前依赖适配器支持 `voiceurl`；不同适配器的兼容性尚需验证。
- 推理端：Python、Node.js、FFmpeg、NVIDIA GPU、`server/requirements.txt` 和 `server/package.json` 中的依赖。
- 需要自行准备 RVC、UVR5、RMVPE、HuBERT 模型，见 [模型说明](server/models/README.md)。确认模型和角色音色有使用授权；音乐音源的获取与使用也应符合相应授权和服务条款。
- 当前 UVR5 分离代码使用 GPT-SoVITS 的 `tools/uvr5/vr.py`，可设置 `UVR5_TOOLS_DIR` 指向包含该文件及其依赖的目录。它不依赖 GPT-SoVITS 的 TTS 服务进程，但依赖这部分代码及其环境。

## 启动推理服务

在 Windows NVIDIA GPU 机器上可尝试双击 `server/install_windows.bat` 准备独立环境，并按提示选择有权使用的 RVC v2 音色模型；安装器尚处验证阶段，见[部署指南](docs/deployment.md)。也可以按指南手动准备环境，复制 `server/settings.example.json` 为 `server/settings.json` 并填写路径。默认只监听 `127.0.0.1:9881`。如果 MaiBot 位于另一台机器，请先阅读 [EasyTier 组网教程](docs/easytier.md)。

网易云登录凭据可通过环境变量 `NETEASE_MUSIC_U` 提供，也可放入 `server/.music_u` 文件。该文件已加入忽略列表，不应提交或分享；未配置凭据时只能尝试账户无需登录即可获取的内容。凭据必须由使用者自行取得。

无需强制开通 VIP：程序依次尝试无损、极高、较高和标准音质，以平台实际返回的完整音频为准，并跳过标记为试听的音源。是否可用取决于歌曲版权、地区、登录状态及账号权益；无权播放或平台没有的曲目不会因此变得可用，搜索也可能返回同名或翻唱版本。

SVIP 在歌曲支持且账号具备相应权益时可能取得更高音质的音源，演唱效果有机会更好；非 VIP 也可以使用，但部分歌曲的音源质量或可用范围可能较低。实际效果还取决于原曲、模型和混音设置。

非本机监听要求配置服务令牌；应通过可信加密网络传输并限制访问。`settings.json`、`.music_u` 和生成的 `config.toml` 属于本地配置，不要公开或提交。

## 安装插件

未来上架后，用户可以在 MaiBot 插件市场一键安装本插件；安装只完成 **MaiBot 端**，不会在服务器自动下载模型、启动 GPU 服务或创建 EasyTier 网络。上架之前也可以将本仓库安装到 MaiBot 的 `plugins/` 下。

安装后还需在有 NVIDIA 显卡的机器部署推理服务，见[部署指南](docs/deployment.md)。同一台机器且同一网络命名空间运行时，WebUI 保持默认地址 `http://127.0.0.1:9881`；云端 MaiBot 则填写 GPU 电脑可达的虚拟地址，并按需配置令牌，参见 [EasyTier 教程](docs/easytier.md)。如果两者位于不同容器，`127.0.0.1` 并不互通。

填写后发送 `/唱歌状态` 检查连接，再使用 `/唱 歌名`。音频临时目录留空时使用插件运行时目录；如果适配器无法访问该目录，可配置它与 MaiBot 共享的绝对路径。适配器位于不同容器时，同样需要共享路径。

插件入口和 Manifest 已放在仓库根目录。向官方插件中心提交前，仍需根据实际测试的 MaiBot 与 SDK 版本设置兼容范围、推送公开仓库并发布 GitHub Release。
Manifest 暂以 MaiBot 1.3.17 为最低目标版本，SDK 区间为待验证的候选范围；它们不代表已经完成端到端兼容测试。

现有未配置令牌的旧服务可将插件的 `server_token` 留空；新服务配置了 `SING_API_TOKEN` 后，两端需使用相同令牌。升级现网时应先验证新版本并准备回退方案。

## 常见问题

- 服务启动时无法导入 `vr`：检查 `UVR5_TOOLS_DIR`、相关依赖和模型路径。
- 访问服务返回 401：确认客户端和服务端令牌一致。
- 生成成功但没有语音：确认适配器支持 `voiceurl`，且能读取插件生成的音频路径。
- 无法获得歌曲：检查音乐账号的登录状态、可用曲目和对应权益。

现有实现及依赖在其他机器上的兼容性尚未完成验证；技术交接文档中的环境状态属于历史记录。
