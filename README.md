## ✨ 它能做什么

- 发送命令或通过自然对话点歌，生成演唱片段并发送语音。
- 尝试获取完整歌曲音源，进行人声分离、音高分析、RVC 音色转换和混音。
- 通过变调、时长等参数调整效果，也可以对上一首歌重新生成。
- 支持 MaiBot 和推理服务同机运行，也支持云端 MaiBot 连接家里的 GPU 电脑。

## 🧩 选择部署方式

| | 本地一体化 | 云端 + 本地 GPU |
| --- | --- | --- |
| MaiBot | 运行在自己的电脑上 | 运行在云服务器 |
| 推理服务 | 同一台有 NVIDIA GPU 的电脑 | 家里的 NVIDIA GPU 电脑 |
| 连接方式 | 默认 `http://127.0.0.1:9881` | 使用 EasyTier 等可信网络，配置可达地址和服务令牌 |
| 适合 | 只用一台电脑 | 云服务器显卡性能不足 |

两种方式使用**同一份 MaiBot 插件**。插件安装不会自动安装显卡环境、下载模型或建立组网；GPU 电脑还需要单独准备推理服务。

## 💻 运行需求

| 项目 | 需求和已验证情况 |
| --- | --- |
| MaiBot | 已实测 **1.3.17 + SDK 2.19.0**；清单声明 MaiBot 1.3.17–1.3.99、SDK 2.19.0–2.19.99，其他版本尚未逐一验证 |
| 语音适配器 | 需要支持 `voiceurl` 自定义消息，并能访问生成的音频文件；其他适配器兼容性待验证 |
| 推理电脑 | 一键安装器面向 **64 位 Windows + NVIDIA GPU**，需兼容 CUDA 11.8 的显卡和驱动 |
| 显存与性能 | 已在 RTX 4070 Laptop 上生成短唱段；**最低显存和其他 GPU 的速度尚未系统测量**，显存占用与模型、歌曲长度及并发有关 |
| 硬盘与网络 | GPU 端建议至少预留 **15 GB**；首次安装需下载数 GB 的运行环境和基础模型，并需要稳定网络 |
| 音色模型 | 自行准备有使用权限的 **RVC v2 `.pth`**，可选配套 `.index`；GPT-SoVITS 的 TTS 模型不能直接作为 RVC 音色 |

Windows 安装器会准备独立的 Python、PyTorch、Node.js、FFmpeg、UVR5 代码和基础模型；Linux 或手动安装参考[部署指南](docs/deployment.md)。全新且没有 C++ 编译工具的 Windows 电脑尚未完成独立端到端验证。

## 🚀 快速开始

1. **安装 MaiBot 插件**：在 MaiBot WebUI 中通过 Git 地址安装本仓库 `https://github.com/real-Elysia886/sing`，然后启用。插件尚未进入官方插件市场；审核上架后才可在市场中搜索安装。
2. **准备 GPU 推理服务**：在 GPU 电脑获取本仓库，双击 `server/install_windows.bat`，按提示选择自己的 RVC v2 音色模型。安装结束后运行 `server/start_server.bat`。
3. **连接服务**：同机运行时，WebUI 中填写默认地址 `http://127.0.0.1:9881`。云端连接本地电脑请参考 [EasyTier 组网教程](docs/easytier.md)，设置可达地址和服务令牌。
4. **检查并点歌**：向 MaiBot 发送 `/唱歌状态`，连接正常后发送 `/唱 歌名`。

完整步骤和手动安装方式见 [部署指南](docs/deployment.md)，模型准备见 [模型说明](server/models/README.md)。不同容器中的 `127.0.0.1` 不互通；适配器与 MaiBot 位于不同容器时也需要共享音频目录。

## 🎤 点歌指南

| 命令 | 用途 |
| --- | --- |
| `/唱 晴天` | 搜索歌曲并生成唱段 |
| `/唱 晴天 变调=+8 时长=13` | 指定变调和唱段时长 |
| `/重唱 +8` | 使用上一首歌重新生成 |
| `/唱歌状态` | 检查推理服务连接 |
| `/清空唱段` | 清理历史音频切片缓存 |
| `/唱 帮助` | 查看完整调音选项 |

默认男声变调基准为 +8 半音，自动变调还会根据检测结果调整；实际效果取决于音源、音色模型和混音设置。

## 🎧 音源与账号

无需强制开通 VIP：程序依次尝试无损、极高、较高和标准音质，跳过标记为试听的音源。实际可用性取决于歌曲版权、地区、登录状态与账号权益，搜索也可能返回同名或翻唱版本。

SVIP 在歌曲和账号权益支持时可能取得更高质量的音源，演唱效果有机会更好；非 VIP 也能使用，但部分歌曲的音源质量或可用范围可能较低。未配置账号时，只能尝试无需登录即可获取的内容。

如需登录，由使用者自行取得网易云 `MUSIC_U` 并设置环境变量 `NETEASE_MUSIC_U`，或写入 `server/.music_u`。**不要公开或分享账号凭据、服务令牌、`settings.json` 和生成的 `config.toml`。**

## ❓ 常见问题

- **插件安装后不能唱歌？** 插件和推理服务是两个部分。先在 GPU 电脑安装并启动服务，再用 `/唱歌状态` 检查。
- **找不到歌曲或只能试听？** 平台可能没有版权或当前账号没有完整播放权限；换一首有权播放的歌曲试试。
- **提示无法导入 `vr`？** 检查 `uvr_tools_dir` 是否指向包含 `vr.py` 和配套模块的目录，详见[部署指南](docs/deployment.md)。
- **连接返回 401？** 检查插件和推理服务的令牌是否一致。
- **生成成功但没有语音？** 检查适配器是否支持 `voiceurl`，以及是否能够读取音频文件。
