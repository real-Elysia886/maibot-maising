# MaiSing 1.1.0

- 优化歌名、歌手和歌词搜索，优先确认歌曲身份，并改进唱段选择。
- 无法确认歌曲或获取完整音源时给出提示；识别到翻唱或替代版本时说明版本。
- 自然对话中支持由麦麦根据氛围或风格选择具体歌曲。
- 点歌与重唱支持全角变调输入，例如 `＋8`；重唱时不再额外发送调音信息。
- 修正调音参数说明，补充 MaiBot 插件和独立推理服务的升级步骤。

升级时请同时更新 MaiBot 插件和 GPU 电脑上的推理服务，详见[部署指南](https://github.com/real-Elysia886/maibot-maising/blob/v1.1.0/docs/deployment.md#6-升级现有部署)。已有服务如有自行修改，请先比较并备份；保留模型、配置和账号凭据。
